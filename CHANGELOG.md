# Changelog

## 1.3.0 — 2026-10-20

- New series: **Neko Hoodie** (2 variations: anime 3D + pixel art). `neko-hoodie/neko-hoodie-1` set as the active Muse avatar.

## 1.2.1 — 2026-10-20

- Added the 4 animations of the active theme (idle, working, making-something, milestone) to `kimono/kimono-1/animations/`.

## 1.2.0 — 2026-10-20

- New series: **Kimono** (4 variations of a swordswoman in a white kimono, from one reference artwork). `kimono/kimono-1` set as the active Muse avatar.

## 1.1.0 — 2026-10-20

- Restructured: the four Anime Angel themes moved from the repository root into a single series folder, `anime-angel/` (one folder per series, one folder per theme inside it), to keep the root clean as more themes are added.

## 1.0.0 — 2026-10-20

- Initial release: the **Anime Angel** theme set (4 variations generated from one reference artwork).
- `anime-angel-1` set as the active Muse avatar, with its 4 animations (idle, working, making-something, milestone).
- `anime-angel-2` (anime, closest to reference), `anime-angel-3` (semi-realistic) and `anime-angel-4` (pixel art) saved as switchable themes.
